Privacy Policy

Last updated: September 5, 2026

Overview

UAEJobs is a local-first job-search companion. It organizes LinkedIn job-alert emails, analyzes selected job postings, and helps users track job applications.

Google data UAEJobs accesses

When a user connects Gmail, UAEJobs requests read-only Gmail access. This permission technically allows the application to read Gmail data. UAEJobs uses it only to locate and process LinkedIn job-alert emails for the connected user.

UAEJobs may process the connected Gmail account identifier, Gmail message identifiers, message headers, and the contents of matching LinkedIn job-alert emails.

How Google data is used

Google data is used only to:

  • Find LinkedIn job-alert emails.
  • Extract job titles, companies, locations, and job links.
  • Prevent the same email or job from being imported twice.
  • Display imported jobs inside the UAEJobs application.

UAEJobs cannot send, modify, or delete email. It does not use Gmail data for advertising, marketing, credit decisions, or surveillance.

Local storage

UAEJobs processes and stores imported job information locally on the user’s computer. OAuth credentials are also stored locally and are not included in the public UAEJobs website or source repository.

UAEJobs does not operate a remote database for Gmail messages, job history, application records, or candidate profiles.

Sharing and selling information

UAEJobs does not sell Google user data or personal information. It does not share Gmail data with advertisers, data brokers, or unrelated third parties.

Data retention and deletion

Imported job records remain on the user’s computer until the user removes them. Users can disconnect Gmail and delete locally stored UAEJobs data at any time.

Revoking UAEJobs access through the Google Account permissions page prevents future Gmail access.

Security

UAEJobs uses OAuth authorization and requests only read-only Gmail access. The browser connector listens only on the local computer and is not exposed as a public internet service.

Google API Limited Use disclosure

UAEJobs’ use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements.

Changes to this policy

This policy may be updated when UAEJobs features or data practices change. The latest version and revision date will remain available on this page.
